# CodePilot – AI Coding Assistant: SQL Business Analysis

## 📌 Project Overview

**CodePilot** is a fictional AI-powered coding assistant designed to support software development teams with activities such as code completion, chat, and code review.

This project uses **SQL** to analyze how CodePilot is being used across developers, customers, teams, and features. The analysis also compares product usage with customer revenue to identify useful business insights.

The goal of this project is to demonstrate how SQL can be used to answer **business-driven questions using data**.

---

## 🎯 Business Objectives

The analysis focuses on the following business questions:

- Measure developer adoption of CodePilot
- Compare usage across customers and teams
- Identify the most frequently used features
- Analyze usage trends over time
- Compare CodePilot usage with customer revenue
- Identify additional business questions from the analysis

---

## 🗂️ Dataset

The project uses a dummy dataset containing four related tables:

| Table | Description | Records |
|---|---|---:|
| `customers` | Customer details and subscription plans | 4 |
| `developers` | Developers, their customers, and teams | 12 |
| `usage_events` | CodePilot usage activity | 24 |
| `monthly_revenue` | Monthly revenue generated by customers | 12 |

### Relationships

```text
Customers
    │
    ├── Developers
    │       │
    │       └── Usage Events
    │
    └── Monthly Revenue
```

The dataset covers **January to March 2026** and is created specifically for SQL analysis and demonstration.

---

## 🔍 Business Analysis

### 1. Developer Adoption

**Question:**  
How many developers are actively using CodePilot, and how many are inactive?

A developer is considered **Active** if they have at least one usage event. Developers with no usage events are considered **Inactive**.

**Result:**
- 10 active developers
- 2 inactive developers
- Overall adoption level: **83.33%**

**SQL concepts used:**
- `CASE WHEN`
- `COUNT()`
- `LEFT JOIN`
- `GROUP BY`
- Subqueries

---

### 2. Customer and Team Usage

**Question:**  
Which customers and teams use CodePilot the most?

Usage events are aggregated by customer and team to compare their CodePilot activity.

**Key finding:**
- AlphaTech and CloudNova together account for **75% of all usage events**
- Platform and Data teams have the highest usage

**SQL concepts used:**
- `JOIN`
- `LEFT JOIN`
- `COUNT()`
- `SUM()`
- `COALESCE()`
- `GROUP BY`
- `ORDER BY`

---

### 3. Feature Usage

**Question:**  
Which CodePilot features are used most frequently?

Usage events are grouped by feature type, including:

- Code completion
- Chat
- Code review

**Key finding:**

**Code completion** is the most frequently used feature, representing **66.67% of all usage events**.

**SQL concepts used:**
- `COUNT()`
- `GROUP BY`
- `ORDER BY`

---

### 4. Usage Over Time

**Question:**  
How does CodePilot usage change from month to month?

Usage is analyzed by month using usage events, active developers, and accepted suggestions.

**Key finding:**

| Month | Usage Events |
|---|---:|
| January | 10 |
| February | 10 |
| March | 4 |

Usage decreased significantly in March, with active developers decreasing from **8 to 4**.

**SQL concepts used:**
- `DATE_FORMAT()`
- `COUNT()`
- `COUNT(DISTINCT)`
- `SUM()`
- `GROUP BY`
- `ORDER BY`

---

### 5. Usage vs Revenue

**Question:**  
Is higher CodePilot usage associated with higher customer revenue?

Customer usage and revenue are calculated separately and then compared.

**Key finding:**

AlphaTech and CloudNova have relatively high CodePilot usage as well as high three-month revenue.

However, this analysis **does not establish that higher usage causes higher revenue**.

An interesting observation is that **March usage decreased while revenue continued to increase**.

**SQL concepts used:**
- `JOIN`
- `LEFT JOIN`
- Subqueries
- `COUNT()`
- `SUM()`
- `COALESCE()`
- `GROUP BY`

---

### 6. Additional Business Question

**Question:**  
Why did CodePilot usage decline sharply in March, particularly for some customers, while revenue continued to increase?

The March usage was compared across customers to identify where the decline occurred.

**Key finding:**

- BetaWorks recorded **0 usage events** in March
- DeltaSoft recorded **0 usage events** in March
- AlphaTech and CloudNova continued using CodePilot

This shows that the March decline was **not uniform across all customers** and requires further investigation.

Possible areas for further investigation include:

- Developer engagement
- Feature adoption
- Training
- Product issues
- Customer-specific factors

## 📊 Key Findings

- **83.33%** of developers are active.
- **AlphaTech and CloudNova** account for **75% of usage events**.
- **Platform and Data** teams have the highest usage.
- **Code completion** is the most frequently used feature.
- Usage remained at 10 events in January and February but dropped to **4 events in March**.
- Active developers decreased from **8 to 4** in March.
- Higher-usage customers also show higher revenue in this sample, but this does not prove causation.
- Revenue continued to increase even while March usage decreased.
- BetaWorks and DeltaSoft had no usage events in March.
